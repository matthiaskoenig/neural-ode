# SBML test suite

Every semantic case of the [SBML test suite](https://github.com/sbmlteam/sbml-test-suite) is simulated with roadrunner (`roadrunner`), converted to a JAX module (`sbml2jax`) and simulated with diffrax (`jax`); both simulations are compared with the expected results of the case with the tolerances of the case. Solver tolerances of both simulators: relative 1e-09, absolute 1e-12.
